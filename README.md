# 📊 Employee Attendance Tracker | Excel Project      

## 📌 Project Overview

The **Employee Attendance Tracker** is an Excel-based project designed to organize employee attendance records in a structured and accessible format.

This project demonstrates the practical use of Microsoft Excel for attendance management, data organization, and presenting information in a clear visual format.

It is part of my journey toward becoming a **Data Analyst**, where I am developing my skills in spreadsheet analysis, data presentation, and reporting.
